# B11 — Animal Kingdom Classification 📘 Priority 3

> **Exam Importance:** Major phyla (especially Arthropoda, Chordata, Annelida), key features of each group, vertebrate classes, and important animal facts are tested at moderate frequency.

## 1. Classification Hierarchy

```
Kingdom → Phylum → Class → Order → Family → Genus → Species
"King Phillip Came Over For Good Soup"
```

**Animal Kingdom (Animalia):** Eukaryotic, multicellular, heterotrophic, no cell wall, most can move.

---

## 2. Major Phyla — Complete Table

| Phylum | Key Features | Examples | PYQ |
|--------|-------------|---------|-----|
| **Porifera** | Pores (ostia) throughout body; no true tissues; sessile; simplest multicellular animals | Sponges (*Sycon*, *Spongilla*) | 📘 |
| **Coelenterata (Cnidaria)** | Hollow body; radial symmetry; stinging cells (cnidocytes/nematocysts); 2 tissue layers (diploblastic) | Jellyfish, Hydra, Coral, Sea anemone | ⭐ |
| **Platyhelminthes** | Flatworms; bilaterally symmetrical; no coelom (acoelomate); organ-system level | Tapeworm (*Taenia*), Planaria, Liver fluke | ⭐ |
| **Aschelminthes (Nematoda)** | Round/cylindrical worms; pseudocoelomate; complete digestive tract | Roundworm (*Ascaris*), Pinworm, Hookworm, Filarial worm (*Wuchereria*) | ⭐ |
| **Annelida** | Segmented worms; true coelom; complete digestive tract; closed circulatory system | Earthworm (*Pheretima*), Leech, Nereis | 🔥 |
| **Arthropoda** | **Largest phylum** (most species); jointed appendages; exoskeleton (chitin); open circulatory system | Insects, Crab, Shrimp, Spider, Scorpion, Centipede, Millipede | 🔥 |
| **Mollusca** | Soft body; mantle; shell (usually); open circulatory system (except octopus); radula (tongue-like) | Snail, Oyster, Squid, Octopus, Clam | ⭐ |
| **Echinodermata** | Spiny skin; water vascular system (tube feet); radial symmetry (adult); can regenerate | Starfish (*Asterias*), Sea urchin, Sea cucumber, Brittle star | 📘 |
| **Chordata** | Notochord at some stage; dorsal hollow nerve cord; pharyngeal gill slits; post-anal tail | All vertebrates + some invertebrates | 🔥 |

> **Arthropoda = Largest phylum** by number of species (~1 million described species; 80% of all animal species)

---

## 3. Phylum Chordata — Subphyla

| Subphylum | Feature | Example |
|-----------|---------|---------|
| **Urochordata** (Tunicata) | Notochord only in larva | Sea squirt (*Ascidia*) |
| **Cephalochordata** | Notochord throughout body | Amphioxus/Lancelet |
| **Vertebrata** | Vertebral column replaces notochord | All vertebrates |

---

## 4. Vertebrate Classes — Comparison Table

| Class | Common Name | Key Features | Examples | PYQ |
|-------|------------|-------------|---------|-----|
| **Pisces** | Fish | Aquatic; gills for respiration; scales; cold-blooded (ectothermic); 2-chambered heart | Rohu, Catla, Shark, Eel | ⭐ |
| **Amphibia** | Amphibians | Live on land AND water; moist skin; lungs + skin respiration; cold-blooded; 3-chambered heart; lay eggs in water | Frog, Toad, Salamander | 🔥 |
| **Reptilia** | Reptiles | Land animals; dry scaly skin; lungs; cold-blooded; 3-chambered heart (4 in crocodile); internal fertilisation; amniotic eggs | Snake, Lizard, Turtle, Crocodile | 🔥 |
| **Aves** | Birds | Warm-blooded (endothermic); feathers; hollow bones (flight); 4-chambered heart; high metabolic rate; lay eggs | Pigeon, Crow, Eagle, Penguin (flightless but still Aves!) | 🔥 |
| **Mammalia** | Mammals | Warm-blooded; hair/fur; mammary glands (nurse young with milk); 4-chambered heart; diaphragm | Human, Dog, Whale, Bat, Platypus | 🔥 |

## 6. Heart Chambers by Class

| Class | Heart Chambers |
|-------|---------------|
| Fish (Pisces) | **2 chambers** (1 auricle, 1 ventricle) |
| Amphibia | **3 chambers** (2 auricles, 1 ventricle) |
| Reptilia (most) | **3 chambers** (incomplete septum) |
| Crocodile | **4 chambers** (only reptile) |
| Birds (Aves) | **4 chambers** |
| Mammals | **4 chambers** |
