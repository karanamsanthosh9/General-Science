## 1. Modes of Reproduction

### 1.1 Asexual Reproduction

- **Definition:** Involves only ONE parent; no fertilisation; offspring genetically identical to parent (clones)
- **Advantages:** Fast, no need for mate, efficient in stable environments
- **Disadvantage:** No genetic diversity

| Method | Description | Examples |
|--------|-------------|---------|
| **Binary fission** | Cell divides into two equal halves | Amoeba, bacteria, paramecium |
| **Budding** | Outgrowth (bud) forms and detaches | Yeast, Hydra, sponges |
| **Fragmentation** | Body breaks into pieces; each grows into new organism | Planaria (flatworm), sea stars, some algae |
| **Regeneration** | Ability to regrow lost parts (extreme = new organism from part) | Hydra, starfish, Planaria |
| **Sporulation** | Formation of spores (reproductive units) | Moulds (*Mucor*, *Rhizopus*), ferns, mosses |
| **Vegetative propagation** | New plant from vegetative parts | Potato (tuber), onion (bulb), ginger (rhizome), banana (runner) |
| **Parthenogenesis** | Development from unfertilised egg | Honeybees (drones = unfertilised), some lizards, aphids |

### 1.2 Sexual Reproduction

- **Definition:** Involves TWO parents; fusion of gametes (fertilisation); genetic diversity in offspring
- **Advantages:** Genetic diversity → adaptability; evolution possible
- **Disadvantage:** Slower; requires mate

## 2. Human Male Reproductive System

| Organ | Function |
|-------|---------|
| **Testes** (primary sex organ) | Produce sperm (spermatogenesis) and testosterone; located in scrotum (outside body, ~2°C below body temp for sperm production) |
| **Epididymis** | Sperm maturation and storage |
| **Vas deferens** | Transports sperm from epididymis to urethra |
| **Seminal vesicles** | Produce ~60% of semen (fructose for sperm energy) |
| **Prostate gland** | Produces alkaline fluid (neutralises vaginal acidity) |
| **Bulbourethral glands (Cowper's)** | Lubricating fluid |
| **Urethra** | Common passage for urine and semen |
| **Penis** | Organ of copulation; urination |

**Spermatogenesis:**
- Begins at puberty; continuous throughout male life
- Sperm produced: ~300 million per day
- Sperm structure: head (nucleus, acrosome), midpiece (mitochondria), tail (flagellum)
- Mature sperm: smallest human cell

---

## 3. Human Female Reproductive System

| Organ | Function |
|-------|---------|
| **Ovaries** (primary sex organ) | Produce eggs (oogenesis) and female hormones (oestrogen, progesterone) |
| **Fallopian tubes (Oviducts)** | Transport egg from ovary to uterus; site of FERTILISATION |
| **Uterus (Womb)** | Site of implantation and fetal development; muscular walls contract during labour |
| **Endometrium** | Inner lining of uterus; shed during menstruation if no pregnancy |
| **Cervix** | Lower part of uterus; gateway between uterus and vagina |
| **Vagina** | Birth canal; receives penis during copulation |
| **Hymen** | Thin membrane at vaginal entrance |

**Oogenesis:**
- Begins before birth (all eggs formed during fetal development)
- ~2 million primary oocytes at birth → ~400,000 at puberty → ~400–500 released over lifetime
- One egg released per month (ovulation)

## 4. Menstrual Cycle

**Duration:** ~28 days (average; 21–35 days normal range)

| Phase | Days | Events | Hormones |
|-------|------|--------|---------|
| **Menstrual phase** | Days 1–5 | Uterine lining shed (menstruation); estrogen + progesterone fall | FSH begins rising |
| **Follicular phase** | Days 1–13 | Follicle develops in ovary; estrogen rises; endometrium thickens | FSH, LH (beginning rise), Estrogen |
| **Ovulation** | Day 14 | Egg released from ovary (LH surge triggers) | LH surge; Estrogen peak |
| **Luteal phase** | Days 15–28 | Empty follicle → corpus luteum; progesterone high; endometrium maintained | LH, Progesterone |
| **If NO pregnancy:** Corpus luteum degenerates → progesterone falls → menstruation begins again |

**Key hormones:**
- **FSH** (Follicle-Stimulating Hormone) from pituitary → stimulates follicle growth
- **LH** (Luteinising Hormone) from pituitary → triggers ovulation; stimulates corpus luteum
- **Estrogen** from ovary → thickens endometrium; secondary sex characteristics
- **Progesterone** from corpus luteum → maintains endometrium for implantation; "hormone of pregnancy"
- **hCG** (human chorionic gonadotropin) → secreted by embryo → prevents menstruation; detected in pregnancy tests

## 5. Fertilisation and Development

```
Ovulation → Egg in fallopian tube → Sperm + Egg → Fertilisation (in fallopian tube)
→ Zygote → Cleavage (mitotic divisions) → Morula → Blastocyst → Implantation in uterus
→ Embryo → Fetus → Birth (after ~40 weeks / 9 months)
```

**Key Events:**

| Event | Location | Time |
|-------|---------|------|
| Fertilisation | Fallopian tube (ampulla) | ~6–12 hours after ovulation |
| Implantation | Uterine wall | Day 6–10 after fertilisation |
| Placenta formation | Uterine wall | ~Weeks 2–3 |
| Heartbeat begins | — | ~Week 6 |
| Organogenesis | — | Weeks 3–8 (critical period) |
| Full term | — | ~40 weeks |

**Placenta:**
- Connects fetus to uterine wall via umbilical cord
- Exchange of O₂, nutrients, waste between maternal and fetal blood
- Produces progesterone and estrogen during pregnancy
- Acts as barrier (most, but not all, pathogens and drugs blocked)

## 6. Assisted Reproductive Technologies

| Technology | Description |
|-----------|-------------|
| **IVF (In Vitro Fertilisation)** | Egg + sperm fertilised outside body in lab → embryo transferred to uterus; "test-tube baby" |
| **IUI (Intrauterine Insemination)** | Sperm injected directly into uterus |
| **ICSI** | Single sperm injected directly into egg |
| **Surrogacy** | Another woman carries the pregnancy |
| **GIFT/ZIFT** | Gametes or zygote placed in fallopian tube |

**First test-tube baby:** **Louise Brown** (UK, 1978) — IVF by Robert Edwards and Patrick Steptoe.

## 7. Plant Reproduction

### 7.1 Asexual Reproduction in Plants

| Method | Example |
|--------|---------|
| Vegetative propagation | Potato (tuber), ginger (rhizome), onion (bulb), banana (sucker) |
| Budding | Yeast (actually a fungus) |
| Grafting | Mango, rose (scion + rootstock) |
| Cutting | Rose, sugarcane |
| Layering | Jasmine |
| Tissue culture | Mass cloning of plants |

### 7.2 Sexual Reproduction in Flowering Plants

**Flower parts:**

| Part | Function |
|------|---------|
| Stamen (anther + filament) | Male reproductive organ; pollen produced in anther |
| Pistil/Carpel (stigma + style + ovary) | Female reproductive organ; ovule (future seed) in ovary |
| Sepal | Protects flower bud |
| Petal | Attracts pollinators |

**Pollination:**
- **Self-pollination:** Pollen from same flower → same flower
- **Cross-pollination:** Pollen from one flower → another flower; agents: wind, insects, water, birds, bats

**Double fertilisation (unique to angiosperms):**
```
One sperm + egg → Zygote (2n) → Embryo → Baby plant
One sperm + 2 polar nuclei → Endosperm (3n) → Food for embryo
```
