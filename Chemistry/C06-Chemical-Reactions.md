## 1. Chemical Reactions — Definition

A chemical reaction is a process in which reactants are converted into products with a change in chemical composition. Evidence: colour change, gas evolution, precipitate formation, temperature change, light emission.

## 2. Types of Chemical Reactions

### 2.1 Combination (Synthesis) Reaction

```
A + B → AB
2H₂ + O₂ → 2H₂O
CaO + H₂O → Ca(OH)₂ + Heat
C + O₂ → CO₂
```

### 2.2 Decomposition Reaction

```
AB → A + B
2H₂O → 2H₂ + O₂ (electrolysis)
2H₂O₂ → 2H₂O + O₂ (MnO₂ catalyst — H₂O₂ decomposition)
CaCO₃ → CaO + CO₂ (thermal decomposition)
2KClO₃ → 2KCl + 3O₂ (MnO₂, heat)
```

**Types of Decomposition:**
- **Thermal decomposition:** Heat causes breakdown
- **Photodecomposition:** Light causes breakdown (e.g., AgCl → Ag + Cl₂ in sunlight — basis of photography)
- **Electrolytic decomposition:** Electricity causes breakdown

### 2.3 Single Displacement (Replacement) Reaction

```
A + BC → AC + B      (A more reactive than B)
Zn + CuSO₄ → ZnSO₄ + Cu     (Zn displaces Cu)
Fe + CuSO₄ → FeSO₄ + Cu     (Fe displaces Cu)
```

### 2.4 Double Displacement (Metathesis) Reaction

```
AB + CD → AD + CB
AgNO₃ + NaCl → AgCl↓ + NaNO₃   (precipitation)
HCl + NaOH → NaCl + H₂O        (neutralisation)
BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
```

### 2.5 Precipitation Reaction

- When mixing two solutions produces an **insoluble solid (precipitate)**
- AgCl (white precipitate) — test for chloride ions
- BaSO₄ (white precipitate) — test for sulphate ions
- Fe(OH)₃ (reddish-brown precipitate)
- CaCO₃ (white precipitate) — lime water + CO₂ turns milky

### 2.6 Neutralisation Reaction

```
Acid + Base → Salt + Water
HCl + NaOH → NaCl + H₂O
H₂SO₄ + 2KOH → K₂SO₄ + 2H₂O
```

### 2.7 Combustion Reaction

```
Fuel + O₂ → CO₂ + H₂O + Heat/Light
CH₄ + 2O₂ → CO₂ + 2H₂O
C + O₂ → CO₂
2C + O₂ → 2CO (incomplete combustion — carbon monoxide)
```

**Types of combustion:**
- **Complete combustion:** Sufficient O₂ → CO₂ + H₂O (blue flame)
- **Incomplete combustion:** Insufficient O₂ → CO + soot (yellow/orange sooty flame)

### 2.8 Oxidation-Reduction (Redox) Reaction

| Term | Definition (Classical) | Definition (Modern — electron transfer) |
|------|----------------------|----------------------------------------|
| Oxidation | Addition of oxygen OR removal of hydrogen | Loss of electrons (OIL — Oxidation Is Loss) |
| Reduction | Removal of oxygen OR addition of hydrogen | Gain of electrons (RIG — Reduction Is Gain) |
| Oxidising agent | Substance that oxidises another | Gets reduced itself; gains electrons |
| Reducing agent | Substance that reduces another | Gets oxidised itself; loses electrons |

**Memory:**
```
OIL RIG:
Oxidation Is Loss (of electrons)
Reduction Is Gain (of electrons)
```

**Examples:**
```
2Mg + O₂ → 2MgO     Mg = oxidised (losing e⁻); O₂ = oxidising agent
CuO + H₂ → Cu + H₂O  H₂ = reducing agent; CuO = oxidising agent
                      Cu²⁺ is reduced to Cu; H₂ is oxidised to H₂O
```

## 3. Exothermic vs Endothermic Reactions

| Type | Energy Change | Temperature Change | Example |
|------|--------------|-------------------|---------|
| **Exothermic** | Energy RELEASED | Temperature INCREASES | Combustion, neutralisation, respiration, dissolution of NaOH |
| **Endothermic** | Energy ABSORBED | Temperature DECREASES | Photosynthesis, thermal decomposition, dissolution of NH₄NO₃ |

## 4. Oxidation States/Numbers

**Rules for assigning oxidation state:**
1. Free element = 0 (e.g., O₂, Fe, Na = 0)
2. Monatomic ion = charge (e.g., Na⁺ = +1, Cl⁻ = −1)
3. H = +1 (usually); −1 in metal hydrides
4. O = −2 (usually); −1 in peroxides (H₂O₂)
5. Sum of oxidation states in neutral compound = 0
6. Sum in polyatomic ion = charge of ion

**Common Oxidation States:**

| Element | Common Oxidation States |
|---------|------------------------|
| H | +1 (−1 in metal hydrides) |
| O | −2 (−1 in peroxides) |
| Na | +1 |
| K | +1 |
| Mg, Ca | +2 |
| Al | +3 |
| Fe | +2, +3 |
| Cu | +1, +2 |
| Mn | +2, +4, +7 |
| Cr | +3, +6 |
| S | −2, +4, +6 |
| N | −3, +3, +5 |
| Cl | −1, +1, +3, +5, +7 |

## 5. Balancing Chemical Equations

**Rules:**
1. Write unbalanced equation
2. Count atoms of each element on both sides
3. Add coefficients to balance (do NOT change subscripts)
4. Balance metals first, then non-metals, then H, then O

**Example:**
```
Fe₂O₃ + Al → Al₂O₃ + Fe  (Thermite reaction — unbalanced)
Step 1: Fe: 2 on left, 1 on right → multiply Fe on right by 2
Step 2: Fe₂O₃ + Al → Al₂O₃ + 2Fe
Step 3: Al: 1 on left, 2 on right → multiply Al by 2
Fe₂O₃ + 2Al → Al₂O₃ + 2Fe  ✓ (balanced)
```

## 6. Catalysts

| Type | Effect | Example |
|------|--------|---------|
| Positive catalyst | Increases reaction rate | MnO₂ in H₂O₂ decomposition; Pt in Haber process |
| Negative catalyst (Inhibitor) | Decreases reaction rate | Glycerol in H₂O₂ |
| Autocatalyst | Product acts as catalyst | Mn²⁺ in KMnO₄ + oxalic acid |
| Biocatalyst (Enzyme) | Biological catalyst | Amylase (starch), Pepsin (protein), Zymase (fermentation) |
