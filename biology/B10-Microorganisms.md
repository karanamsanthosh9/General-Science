## 1. Types of Microorganisms

| Type | Cell Type | Key Features | Examples |
|------|----------|-------------|---------|
| **Bacteria** | Prokaryotic | No nucleus; cell wall (peptidoglycan); smallest cellular organisms | *E. coli*, *Lactobacillus*, *Staphylococcus*, *Rhizobium* |
| **Virus** | Non-cellular (acellular) | Not cells; protein coat (capsid) + nucleic acid; obligate intracellular parasites | HIV, influenza, COVID-19, bacteriophage |
| **Fungi** | Eukaryotic | Cell wall of chitin; heterotrophs; includes moulds, yeasts, mushrooms | *Penicillium*, *Saccharomyces*, *Aspergillus*, *Mucor* |
| **Protozoa** | Eukaryotic | Single-celled; most are mobile; some parasitic | *Amoeba*, *Plasmodium*, *Paramecium* |
| **Algae** | Eukaryotic (mostly) | Photosynthetic; in water | *Spirogyra*, *Chlorella*, Diatoms, Cyanobacteria (prokaryotic) |
| **Archaea** | Prokaryotic | Extremophiles; ancient lineage | Methanogens, halophiles, thermophiles |

## 2. Bacteria — Beneficial Uses

| Benefit | Organism | Process |
|---------|---------|---------|
| **Curd/Yogurt** | *Lactobacillus* spp. | Ferments lactose → lactic acid → sour curd |
| **Nitrogen fixation** (legumes) | *Rhizobium leguminosarum* | In root nodules; fixes N₂ → NH₄⁺/NO₃⁻ for plants |
| **Nitrogen fixation** (free-living) | *Azotobacter*, *Clostridium* | In soil |
| **Vinegar** | *Acetobacter aceti* | Oxidises ethanol → acetic acid |
| **Cheese production** | Various lactic acid bacteria | Fermentation |
| **Silage** | Lactic acid bacteria | Fermentation of green fodder |
| **Soil fertility** | Many decomposer bacteria | Break down organic matter → nutrients |
| **Sewage treatment** | Mixed bacteria | Aerobic digestion of organic waste |
| **Bioleaching** | *Thiobacillus* | Extract metals from low-grade ores |
| **Bioremediation** | Various | Break down oil spills, pollution |
| **Antibiotic production** | *Streptomyces* | Streptomycin, tetracycline, erythromycin |

---

## 3. Fungi — Beneficial Uses

| Benefit | Organism | Application |
|---------|---------|------------|
| **Penicillin** (first antibiotic) | *Penicillium notatum* | Kills gram-positive bacteria; discovered by Alexander Fleming (1928) |
| **Bread/Beer/Wine** | *Saccharomyces cerevisiae* (Baker's/Brewer's yeast) | Fermentation: glucose → ethanol + CO₂; CO₂ makes bread rise |
| **Citric acid** | *Aspergillus niger* | Industrial production of citric acid (food additive) |
| **Cheese ripening** | *Penicillium roqueforti* (blue cheese), *P. camemberti* | Flavour development |
| **Cyclosporin** (immunosuppressant) | *Trichoderma polysporum* (fungus) | Prevents organ rejection |
| **Ergot compounds** | *Claviceps purpurea* | Medical alkaloids |
| **Food** | Mushrooms (*Agaricus*) | Edible fungi |

## 4. Viruses — Key Properties

| Property | Detail |
|---------|--------|
| Discovery | Dmitri Ivanovsky (1892) — first evidence; Martinus Beijerinck coined "virus" |
| Nature | Non-cellular; at boundary of living and non-living |
| Size | 20–300 nm (smallest microorganism) |
| Structure | Nucleic acid (DNA or RNA, NOT both) + Protein coat (capsid) + some have envelope |
| Replication | ONLY inside living host cells |
| Classification by nucleic acid | DNA viruses (Herpes, Hepatitis B, Pox) vs RNA viruses (HIV, Influenza, Dengue, COVID-19) |
| Can they be killed by antibiotics? | NO — antibiotics are ineffective against viruses |

**Bacteriophage (Phage):**
- Virus that infects bacteria
- Important in molecular biology research
- Lytic cycle (kills bacteria) vs Lysogenic cycle (integrates into bacterial DNA)

## 6. Important Microbiology Discoveries

| Discovery | Scientist | Year |
|-----------|----------|------|
| Microbial world | Antonie van Leeuwenhoek (first to observe) | 1670s |
| Germ theory of disease | Louis Pasteur and Robert Koch | 1860s–1880s |
| Pasteurisation | Louis Pasteur | 1860s |
| Koch's postulates | Robert Koch | 1884 |
| Penicillin | Alexander Fleming | 1928 |
| Penicillin clinical use | Howard Florey and Ernst Chain | 1940 |
| Structure of bacteriophage | Martha Chase and Alfred Hershey | 1952 |
